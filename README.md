# Digital Signal Processing Projects

MATLAB-based Digital Signal Processing projects covering real-time audio convolution using Overlap-Add and Overlap-Save methods, and frequency-selective signal processing using FFT and FIR filtering.

## Projects

### Project 1 — Real-Time Audio Signal Processing

**Application Area:** Audio Engineering and Digital Signal Processing

FFT-based Overlap-Add (OLA) and Overlap-Save (OLS) methods for efficient long-sequence convolution of audio signals.

### Project 2 — Frequency-Selective Signal Processing

**Application Area:** Communication and Audio Systems

FFT-based spectral analysis and FIR low-pass filtering for frequency-selective signal processing.

## Technologies

- MATLAB
- Fast Fourier Transform (FFT)
- Digital Signal Processing
- FIR Filtering
- Audio Signal Processing
